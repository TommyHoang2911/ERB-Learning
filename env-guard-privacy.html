Privacy Policy — Env Guard

Effective date: August 19, 2026

Env Guard is a Chrome extension that shows a warning banner, a colored border, and a tab-title tag when you visit a website that matches an environment rule you define yourself (for example, marking an internal IP address as "production"). This page explains what data the extension accesses and how it is handled.

Data Env Guard accesses

To decide whether to show a warning on the page you're viewing, Env Guard's content script reads:

  • The current tab's URL — specifically the hostname and port — compared against the rules you configured.
  • The current tab's page title — read and modified only to prepend your chosen environment label (e.g. [PROD]).

This happens entirely on your device, in memory, for the sole purpose of matching the current page against your own rules and rendering the warning UI. It is not logged, kept as a history, or sent anywhere.

Data Env Guard stores

The only data Env Guard stores is what you enter yourself on its Settings page:

  • Your environment rules (host, port, environment label, and color)
  • The extension's enabled/disabled toggle

This is saved locally in your browser profile using Chrome's chrome.storage.local API. It stays on your device, is not linked to any account, and Env Guard has no backend server to send it to.

What Env Guard does not do

  • Does not transmit any data to external servers — the extension has no backend
  • Does not sell, rent, or share data with any third party
  • Does not use data for advertising, analytics, or tracking
  • Does not collect personally identifiable information, passwords, payment information, or the content of the pages you visit
  • Does not use your data for any purpose beyond showing the environment warning

Why each permission is needed

Host permission (<all_urls>)Env Guard's rules can point to any domain or internal IP you choose, so the extension needs to be able to check the URL on any page to compare it against your rules.

Compliance with the Chrome Web Store User Data Policy (Limited Use)

Env Guard's handling of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements:

  • Data is used only to provide the extension's single purpose — detecting and warning about environment matches.
  • We do not sell or transfer user data to third parties.
  • We do not use or transfer user data for purposes unrelated to the extension's single purpose.
  • We do not use or transfer user data to determine creditworthiness or for lending purposes.

Children's privacy

Env Guard is a developer tool and is not directed at children. It does not knowingly collect data from children.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.
